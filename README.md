# ✨ LumaList ✨

A Todo List web application built with Next.js and Firebase.

## Features
- Email/Password authentication
- Google OAuth login
- Add, edit, delete, and complete tasks
- Real-time updates using Firestore
- Input validation and error handling

## How to Run
1. npm install
2. npm run dev
3. Open http://localhost:3000

## Tech Stack
- Next.js
- Firebase Authentication
- Cloud Firestore
- Tailwind CSS

## AI Usage
AI was used to assist in generating, debugging, and improving the code and UI design.
